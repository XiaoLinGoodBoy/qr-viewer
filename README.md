# Tekla QR ビューア中継ページ

Tekla 図面・製品帳票の QR コードから Trimble Connect の 3D モデルを開き、指定した製品・部材だけを表示するページ。

- QRコード連携ツール（QrLinkApp）：製品符号（`apos`）で表示する
- 製品トレース（ProductTrace）：製品の IFC GUID（`guid`）で**スキャンした 1 個だけ**を表示する（同じ符号の製品が複数あっても区別できる）

## パラメータ

`https://…/qr-viewer/#pid=…&mid=…&stoken=…&guid=…&apos=…` のように `#` 以降に指定する（`?` 以降も可）。
`#` 以降はブラウザからサーバーへ送信されないため、共有トークンがホスティング側のログに残らない。

| 名前 | 内容 |
|---|---|
| `pid` | Trimble Connect プロジェクト ID |
| `mid` | モデル（ファイル）ID |
| `stoken` | 共有トークン（公開リンク）。無い場合は Trimble Connect のビューアへ移動する |
| `org` | 共有リンクの発行元ホスト（例: `app21.connect.trimble.com`） |
| `guid` | 製品の IFC GUID（22 文字、`;` 区切りで複数可）。これで 1 個だけを特定する |
| `sn` | 同一符号内の通し番号（例: `1/3`）。表示用 |
| `apos` / `ppos` | 製品マーク / 部材マーク。`;` 区切り、`?` は任意の 1 文字。`guid` が見つからないときの代わりにも使う |
| `iso=1` | 対象以外を非表示 |
| `ap` / `pp` | 照合するプロパティ名を指定（既定は `ASSEMBLY_POS` / `PART_POS` などを自動判定） |
| `debug=1` | 診断情報を表示 |

## 動作

1. `guid` があれば、Workspace API の `convertToObjectRuntimeIds` で製品（IfcElementAssembly）を特定し、
   `getHierarchyChildren` でその製品の部材・ボルトを取得して表示する。モデル全体のプロパティは読まない。
   - 外部 ID は IFC GlobalId（22 文字）で照合し、見つからなければ UUID 形式（小文字・大文字）でも試す
2. `guid` が見つからない（モデルが古い・製品を作り直した等）場合は `apos` で検索し、
   同じ製品符号の製品をすべて表示したうえで、その旨を警告表示する
3. `guid` の無い QR（QrLinkApp）は従来どおり `apos` / `ppos` で検索する

ヘッダーのボタン：

- **対象を表示**：スキャンした製品に戻る
- **同一符号を表示**：（GUID で特定できたとき）同じ製品符号の製品をすべて表示する
- **全体を表示**：モデル全体
- **部材リスト**：右側（スマートフォンでは下）に製品 → 部材・ボルトの一覧。項目をクリックすると強調してマークを表示

Trimble Connect Workspace API（共有トークンによる埋め込み）を使用。ページ自体はトークンを保存しない。

## 画面

- 右側のリストに製品マーク（`sn` があれば「G1-2 (1/3)」）・部材マーク・ボルト（径×長さ、等級、本数）を表示する。
- ボルトの等級はモデルに無いため、`NAME` の種類から換算している（`TCB` → `S10T`、`HTB` → `F10T`）。
- ボルトには `ASSEMBLY_POS` が無いため、製品の階層（ElementAssembly）から取得する。
